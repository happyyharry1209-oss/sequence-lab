# 數列研究所 · Sequence Lab

以「數列與級數」為主題的中學數學互動學習網站。繁體中文、支援手機，數學計算無須登入或 AI 金鑰。

**[直接使用網站](https://happyyharry1209-oss.github.io/sequence-lab/)**

> 公開網站尚未連接 AI 後端。網站的數學、圖表、辨識、練習及本機導學可使用；OpenRouter 的真實模型呼叫已在本機通過驗證，公開版須部署後端並設定伺服器環境變數後才可使用。金鑰不包含在此儲存庫。本機導學不是 AI 回覆。

## 能做甚麼

- **探索實驗室**：自訂等差、等比、一階線性遞迴，1–200 項；即時數列／前 n 項和圖、逐項播放、數據表及 CSV。
- **規律偵探**：4–30 個自訂數據，檢查一階差分、公比、二階差分、前兩項相加；顯示證據與候選下一項，說明有限數據的非唯一性。
- **生活應用**：閱讀計劃、紙張對摺、詞彙保留模型；改變參數，再帶到實驗台驗證。紙張對摺明確區分 k 次對摺與第 k+1 項。
- **練習挑戰**：六類循環隨機題、提示、逐步解答與本機首次作答紀錄。
- **學習筆記**：公式、推導、特殊情況、收斂條件、模型與計算限制。
- **學習導師**：明確標示的離線本機導學，以及透過安全後端呼叫 OpenRouter 的 AI 導師。無前端 API key 輸入欄。
- **匯出紀錄**：Markdown 報告包含參數、推導、練習結果、數據和自主反思欄位。

## 本機啟動

需要 Node.js 22 或以上。應用程式本身沒有執行期套件依賴。

```sh
npm ci
npm start
```

開啟終端顯示的 `http://localhost:4173`。單純使用靜態版也可把 `docs/` 交給任意 HTTP 靜態伺服器；不要直接以 `file://` 開啟 ES modules。

```sh
npm run check
npm test
```

測試涵蓋數學邊界、辨識、後端來源與驗證、模型呼叫合約、金鑰不外洩及限流。測試使用假的供應商回覆，不會消耗 AI 額度，亦不代表已驗證真實 AI 服務。DOM 模擬測試不取代真實瀏覽器視覺檢查。

## 啟用真正的 AI（Vercel 或自己的 Node 伺服器）

GitHub Pages 是靜態網站，**不能存放伺服器金鑰或直接執行此後端**。前端與後端的部署可以分開。

### 方式 A：Vercel

1. 在 Vercel 匯入本 GitHub 儲存庫；使用根目錄，保留 `vercel.json`（靜態輸出 `docs`，API 在 `api/tutor.mjs`）。
2. **只在 Vercel 專案的環境變數**設定：
   - `OPENROUTER_API_KEY`：你自行建立的 OpenRouter 金鑰。
   - `OPENROUTER_MODEL`：預設 `openrouter/free`。模型供應及額度會變動，可自行選擇帳戶可用模型。
   - `ALLOWED_ORIGINS`：`https://happyyharry1209-oss.github.io`，多個來源以逗號分隔。不要加路徑或結尾斜線。
   - `AI_DAILY_LIMIT`：預設 100，每個伺服器實例每天最多呼叫次數。
3. 部署後，造訪 `https://你的專案.vercel.app/api/tutor`，應回傳 `"ready":true`。這只代表有設定金鑰；還需送出一個真實問題驗證金鑰、模型與額度。
4. 回到 GitHub Pages 網站的「AI 導師」→「設定後端網址」，填 `https://你的專案.vercel.app/api/tutor`。
5. 點擊「詢問 AI」才會送出提問與當前數列參數。若直接使用 Vercel 版本，會自動偵測同源後端。

### 方式 B：本機／自己的 Node 伺服器

複製 `.env.example` 為 `.env`，只在自己的機器修改 `.env`，填入金鑰後執行 `npm start`。`.env` 已由 Git 忽略。`server.mjs` 預設只監聽 `127.0.0.1`，公開部署請使用反向代理、HTTPS 及平台存取保護。

**不要把 key 填入前端、URL、聊天、GitHub README、issue 或 commit。** 如果曾把真實金鑰提交到 Git，僅刪除檔案不足以撤銷，應立即撤銷並重新建立。

## 架構與資料流

```text
瀏覽器 docs/ ── 本機數學核心 math.js ── 圖像／表格／規律分析
      │
      └─ 使用者點擊詢問 AI
           │ POST { message, config }（不含 key，不傳練習紀錄）
           ▼
      /api/tutor 後端
        來源／長度／參數驗證 → 重新計算可信數學上下文 → 限流
           │ 伺服器 Authorization header（key 只在這裡）
           ▼
        OpenRouter 大語言模型 → 純文字教學回覆 → 瀏覽器 textContent
```

AI 是解釋者與蘇格拉底式導師，不是數學運算的唯一來源；即使模型回答錯誤，也不能改變計算器。固定系統提示限制課題範圍、先提示再推導、區分有限資料與唯一規律，並禁止索取個人資料與金鑰。模型輸出不作 HTML 渲染。提示詞本身不能保證抵抗所有提示注入；後端沒有模型可用的工具或外部操作權限。

## 限制及公開部署注意

- 使用 IEEE-754 雙精度浮點數與補償加總，並非符號或任意精度運算。顯示約 11 位有效數字；極端消去／大量次方仍可能失準。每項和總和上限為 10¹⁰⁰，超限顯示錯誤並保留上次有效圖。
- 辨識僅涵蓋四種候選規律；使用約 10⁻¹⁰ 相對容差。沒有偵測到不表示沒有其他規律。
- 後端每 IP 每分鐘最多 8 次，並有每日整體次數限制；這是**記憶體內、單實例**限制，重啟或 serverless 多實例會各自計數。CORS 不是身分驗證，非瀏覽器客戶端仍可呼叫公開 API。
- 公開供多人使用前，應在部署平台加上持久／共享限流或存取驗證，並在 OpenRouter 設定金鑰額度及費用上限；免費模型亦可能受到配額限制。
- 未設定金鑰時回傳 503，不生成假 AI 回覆。2026-11-17 已以本機 HTTP 後端成功取得真實模型回覆，核對範例 a₁=3、d=4、n=12 的 a₁₂=47 與 S₁₂=300；這不代表公開版已接通 AI，亦不保證所有模型回答均正確。
- 練習進度與後端網址只保存在瀏覽器 localStorage；提問與參數送往你選定的後端及 OpenRouter。外部字型由 Google Fonts 載入，無法連線時使用系統字型；沒有分析追蹤程式。

## 約五分鐘的課堂示範

1. 等差：首項 3、公差 4、12 項，驗證第 12 項 47、總和 300；改負公差並播放。
2. 等比：設定 r=1，觀察特殊求和；改 r=−0.8，解釋交替及收斂。
3. 遞迴：p=0.8、q=5，改不同首項，解釋共同平衡點 25。
4. 規律偵探：輸入 1,4,9,16,25，觀察二階差分 2；說明下一項 36 是建立在平方規律假設上。
5. 生活應用：紙厚 0.1mm、12 次對摺，厚度 409.6mm；區分「次數」與「項數」。
6. 完成一道練習，匯出學習紀錄。若已啟用後端，再展示 AI 講解與 Network 面板沒有前端金鑰。
