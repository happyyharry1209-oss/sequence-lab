    05 / THE FIELD NOTES

    記下規律，連起知識。

    公式是起點，理解每一個符號與適用條件才是關鍵。

    01

    等差數列

    相鄰兩項之差相同，稱為公差 d。

    aₙ = a₁ + (n − 1)d
    Sₙ = n(a₁ + aₙ) / 2

    把正序與倒序相加：每列有 n 組 a₁ + aₙ，所以 2Sₙ = n(a₁ + aₙ)。留意第 n 項只有 n−1 次增加。

    02

    等比數列

    從首項起重複乘以固定公比 r。

    aₙ = a₁rⁿ⁻¹
    Sₙ = a₁(1 − rⁿ)/(1 − r)

    上式限 r ≠ 1；r = 1 時，Sₙ = na₁。把 Sₙ 與 rSₙ 相減，可消去中間項。若 |r| < 1，S∞ = a₁/(1−r)。

    03

    遞迴與平衡點

    以前一項定義下一項：aₙ₊₁ = paₙ + q。

    L = q/(1 − p)　(p ≠ 1)
    aₙ − L = (a₁ − L)pⁿ⁻¹

    先解 L = pL + q，再觀察偏離平衡點的距離。|p| < 1 時距離趨近 0；p = 1 時退化成等差數列。

    04

    數列 ≠ 級數

    數列是一列有序的數 a₁, a₂, …；級數則是把各項相加。

    Sₙ = a₁ + a₂ + ⋯ + aₙ
    aₙ = Sₙ − Sₙ₋₁　(n ≥ 2)

    例如 2, 4, 6 的第三項為 6，前三項和為 12。n = 1 時，a₁ = S₁。有限項和與無窮級數也要分清。
